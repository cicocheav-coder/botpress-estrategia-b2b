# 🤖 Chatbot Conversacional de Automatización y Calificación de Leads (B2B)

## 📌 Descripción del Proyecto
Este proyecto fue desarrollado para automatizar la captación y calificación de leads del emprendimiento **Complete Marketing**. El objetivo principal es optimizar el embudo de ventas digital mediante un flujo conversacional inteligente que guía al usuario desde el primer contacto hasta el agendamiento de una reunión comercial o asesoría gratuita.

---

## 🛠️ Arquitectura y Herramientas Utilizadas
El sistema combina herramientas de automatización de marketing y desarrollo conversacional:
- **Botpress:** Plataforma principal para la creación, diseño y lógica de los flujos conversacionales.
- **ChatHelp:** Widget integrado en el sitio web para la captura inicial de datos básicos del lead (Nombre, Apellido, Correo electrónico, etc.).
- **CRM:** Integración directa para el almacenamiento y gestión centralizada de los datos capturados.
- **Canales de Interacción:** Desplegado mediante Webchat y preparado para canales de mensajería como WhatsApp.

---

## 🔄 Estructura de los Flujos y Lógica del Bot

El flujo del bot está diseñado estratégicamente en 3 pasos clave para asegurar una experiencia de usuario fluida y orientada a la conversión:

### 1. Captura de Datos Inicial (Sitio Web)
* El usuario ingresa al sitio web de *Complete Marketing*.
* A través del widget de **ChatHelp**, el sistema solicita y recopila los datos de contacto esenciales del lead (Nombre, Apellido, Correo) antes de iniciar la interacción profunda, enviando esta información en tiempo real al CRM de la empresa.

### 2. Saludo y Presentación de Servicios (Botpress)
* Una vez registrado el lead, el bot lo saluda de forma personalizada utilizando los datos capturados.
* Mediante un sistema de **preguntas cerradas y opciones interactivas**, el bot presenta de forma clara y directa los servicios que ofrece Complete Marketing.
* El usuario selecciona mediante un clic el servicio de su interés específico, permitiendo segmentar su necesidad de inmediato.

### 3. Cierre y Conversión (Call to Action)
* Dependiendo del servicio seleccionado por el lead, el flujo deriva la conversación hacia dos opciones estratégicas de cierre:
  1. **Agendar una Asesoría Gratuita.**
  2. **Coordinar una Llamada Comercial directa.**
* Esto reduce la fricción y maximiza las tasas de conversión a reuniones de ventas.
